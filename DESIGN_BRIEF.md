# Design Brief — Beauty Salon Booking App

## 1. Загальний опис продукту

**Продукт:** Веб-додаток для онлайн-запису в салон краси  
**Стек фронтенду:** Next.js 14+ (App Router), TypeScript, Tailwind CSS, shadcn/ui, Lucide React  
**Аудиторія:** клієнти салону (мобайл + десктоп), майстри (десктоп), адміністратор (десктоп)  
**Мова інтерфейсу:** українська (основна), з можливістю англійської

## 3. Детальний опис кожного екрану

---

### 3.1 Головна сторінка `/`

**Призначення:** First impression для клієнта, заохочує до запису.

**Блоки:**
1. **Hero-секція** — заголовок, підзаголовок, кнопка "Записатись зараз", фонове зображення/градієнт
2. **AI-рекомендації** (якщо авторизований) — картки з персональними пропозиціями від AI-асистента, кнопка "Прийняти"
3. **Список послуг** — картки: назва, тривалість, ціна, кнопка "Обрати"
4. **Список майстрів** — аватар (placeholder), ім'я, спеціалізація, кнопка "Записатись"
5. **CTA-блок** внизу — "Є питання? Запитайте AI-асистента"

**Стани:**
- Неавторизований: показати Hero + послуги + майстри
- Авторизований: додати блок AI-рекомендацій вверху

---

### 3.2 Онлайн-запис `/booking`

**Призначення:** Покроковий процес бронювання. 5 кроків.

**Step 1 — Оберіть послугу:**
- Список карток послуг (назва, тривалість у хвилинах, ціна)
- Вибрана картка підсвічується

**Step 2 — Оберіть майстра:**
- Список карток майстрів (аватар, ім'я, спеціалізація)
- Можливість "Будь-який майстер"

**Step 3 — Оберіть дату:**
- Міні-календар на місяць
- Недоступні дні (немає вільних слотів) — сірі
- Вибрана дата — підсвічена акцентним кольором

**Step 4 — Оберіть час:**
- Сітка доступних таймслотів (09:00, 09:30, 10:00...)
- Зайняті слоти — сірі/неактивні
- Вибраний слот — підсвічений

**Step 5 — Підтвердження:**
- Якщо не авторизований: форма (ім'я, телефон)
- Зведена картка: послуга, майстер, дата, час, тривалість, ціна
- Кнопки "Підтвердити" / "Назад"

**Step 6 — Успіх:**
- Іконка ✓, повідомлення "Запис підтверджено"
- Деталі запису
- Кнопки: "Додати в календар", "Повернутись на головну"

**Навігація:** Прогрес-бар або numbered steps зверху (1–2–3–4–5)

---

### 3.3 Перенесення запису `/booking/reschedule/[id]`

**Призначення:** Вибір нової дати/часу для існуючого запису.

**Блоки:**
- Картка поточного запису (інформаційна, readonly)
- Вибір нової дати (міні-календар)
- Вибір нового часу (слоти)
- Кнопки "Підтвердити перенесення" / "Скасувати"

---

### 3.4 Особистий кабінет клієнта `/dashboard`

**Призначення:** Огляд усіх власних записів.

**Блоки:**
1. **Найближчий запис** — велика картка з деталями + кнопки "Перенести" / "Скасувати"
2. **Список майбутніх записів** — картки зі статусами (`pending`, `confirmed`)
3. **Минулі записи** — більш стримані картки зі статусами (`completed`, `cancelled`)

**Картка запису містить:**
- Назва послуги, майстер, дата і час, статус (badge з кольором), ціна

**Статуси та кольори:**
| Статус | Колір |
|---|---|
| pending | жовтий |
| confirmed | синій/зелений |
| completed | сірий |
| cancelled | червоний |

---

### 3.5 AI-асистент `/ai-assistant`

**Призначення:** Персональний AI-помічник + рекомендації.

**Ліва панель / верхня секція — Рекомендації:**
- Картки рекомендацій від AI (заголовок, текст-обґрунтування, впевненість у %, пропонований час)
- Кнопки "Прийняти" (перейти до запису) / "Відхилити"
- Loader-стан (AI обробляє)

**Права панель / нижня секція — Чат:**
- Bubble-чат інтерфейс (user = права сторона, AI = ліва)
- Поле вводу + кнопка відправки
- Стан завантаження (typing indicator)
- Швидкі кнопки-відповіді (suggestions) з відповіді AI
- Підтримка action-кнопок прямо в чаті ("Забронювати о 10:00")

---

### 3.6 Сповіщення `/notifications`

**Призначення:** Центр сповіщень.

**Список сповіщень:**
- Іконка типу + заголовок + час
- Непрочитані = виділені фоном
- Типи: нагадування про запис, підтвердження, системні

**Фільтри:** Всі / Непрочитані / Прочитані

---

### 3.7 Профіль `/profile`

**Призначення:** Налаштування особистих даних та каналів зв'язку.

**Секції:**
1. **Особисті дані** — ім'я, email, телефон, кнопка "Зберегти"
2. **Канали зв'язку** — Telegram (посилання/підключення), Viber, Email, SMS — тоглери увімк/вимк для: підтвердження, нагадування, маркетинг
3. **Безпека** — зміна паролю
4. **Небезпечна зона** — видалення акаунту

- Кнопка "Увійти"

### 3.9 Реєстрація `/register`

**Форма:**
- Ім'я

- Телефон

- Кнопка "Зареєструватись"
- Посилання "Вже є акаунт? Увійти"

### 3.10 Розклад майстра `/master-dashboard`

**Призначення:** Особистий робочий кабінет майстра.

**Блоки:**
1. **Сьогодні** — timeline-вид дня з записами у вигляді блоків
2. **Список записів** — таблиця або картки: час, клієнт, послуга, статус
3. **Перемикач дат** — навігація вперед/назад по днях

---

### 3.11 Адмін: Дашборд `/admin`

**Призначення:** Загальний огляд стану салону.

**Блоки:**
1. **Статистика (KPI-картки):**
   - Всього записів сьогодні
   - Записів на тиждень
   - Активних майстрів
   - Виручка (якщо доступна)

2. **Останні записи** — таблиця (клієнт, майстер, послуга, час, статус)

3. **AI-інсайти** — картки з бізнес-підказками від AI
   - Приклад: "Низька завантаженість у понеділок вранці — розгляньте акцію"
   - Severity badge (low / medium / high)
   - Кнопки "Прийняти до уваги" / "Відхилити"

---

### 3.12 Адмін: Записи `/admin/appointments`

**Призначення:** Повний CRUD записів.

**Таблиця з колонками:**
- Клієнт, Майстер, Послуга, Дата/Час, Статус, Ціна, Дії

**Фільтри зверху:**
- Дата (від–до)
- Майстер (select)
- Статус (select)

**Дії:**
- Кнопка "Новий запис" → модальне вікно
- На рядку: змінити статус, редагувати, скасувати

---

### 3.13 Адмін: Майстри `/admin/masters`

**Список майстрів** — таблиця або картки:
- Ім'я, email, спеціалізація, статус (active/inactive)
- Дії: Редагувати, Деактивувати

**Кнопка "Додати майстра"** → модаль або drawer:
- Поля: ім'я, email, телефон, спеціалізація, пароль (optional — генерується автоматично)

---

### 3.14 Адмін: Послуги `/admin/services`

**Список послуг** — таблиця:
- Назва, Тривалість (хв), Ціна, Статус
- Дії: Редагувати, Деактивувати

**Кнопка "Додати послугу"** → модаль:
- Поля: назва, тривалість у хвилинах, ціна (необов'язково)

---

### 3.15 Адмін: Розклад `/admin/schedules`

**Призначення:** Налаштування робочих годин майстрів.

**UI:**
- Select майстра зверху
- Тижневий вид: 7 рядків (Пн–Нд)
- Кожен рядок: тоглер "Працює цього дня", поля "Початок" / "Кінець", кнопка "+ Перерва"
- Кнопка "Зберегти розклад"

---

### 3.16 Загальний календар `/calendar`

**Призначення:** Перегляд усіх записів у форматі календаря.

**Перемикач вигляду:** День / Тиждень / Місяць

**День:**
- Колонка часу (09:00–20:00), блоки записів з кольором статусу
- Фільтр по майстру

**Тиждень:**
- Сітка 7 колонок × часові рядки
- Блоки записів у комірках

**Місяць:**
- Класична сітка місяця
- Число на кожному дні + кількість записів

## 5. Дизайн-система

### 5.1 Колірна палітра

Базується на **рожево-нейтральній** тематиці (краса/салон):

| Роль | Приклад кольору |
|---|---|
| Primary | Rose / Pink (відтінки #f43f5e або #ec4899) |
| Background | Білий / дуже світло-сірий (#fafafa) |
| Surface / Cards | Білий із легкою тінню |
| Text | #111827 (dark), #6b7280 (muted) |
| Border | #e5e7eb |
| Success | #22c55e |
| Warning | #f59e0b |
| Error | #ef4444 |
| Info | #3b82f6 |

### 5.2 Типографіка

- **Font:** Inter або Geist (сучасний, читабельний)
- **H1:** 32–40px, bold
- **H2:** 24–28px, semibold
- **H3:** 18–20px, semibold
- **Body:** 14–16px, regular
- **Caption / Label:** 12px, medium

### 5.3 Компоненти shadcn/ui (вже підключено)

Дизайнер може розраховувати на наявність цих компонентів:
- Button (variants: default, outline, ghost, destructive)
- Card, CardHeader, CardContent, CardFooter
- Input, Textarea, Select, Checkbox, Switch
- Dialog / Modal
- Badge
- Avatar
- Tabs
- Table
- DropdownMenu
- Toast / Sonner (notifications)
- Skeleton (loading states)
- Separator
- Sheet (drawer/sidebar)

### 5.4 Іконки

Бібліотека: **Lucide React** — SVG-іконки, розмір 16–24px

Ключові іконки в проекті:
- `Calendar` — записи, календар
- `Clock` — час
- `User`, `Users` — клієнт, майстри
- `Scissors` — послуги (краса)
- `ShieldCheck` — адмін
- `Bot` / `Sparkles` — AI
- `Bell` — сповіщення
- `CheckCircle` — підтвердження
- `X`, `Trash2` — скасування, видалення
- `ChevronLeft`, `ChevronRight` — навігація
- `MessageSquare` — чат

### 5.5 Відступи та радіуси

- Border radius: `rounded-md` (6px), `rounded-lg` (8px), `rounded-xl` (12px)
- Padding картки: 16–24px
- Gap між елементами: 8, 12, 16, 24px (кратно 4)

## 6. Адаптивність

| Breakpoint | Ширина | Поведінка |
|---|---|---|
| Mobile | < 640px | Одна колонка, hamburger menu, спрощений wizard |

## 7. Стани UI (обов'язково вказати у макетах)

Для кожного ключового екрану потрібні стани:
- **Default** — звичайний вигляд
- **Loading / Skeleton** — поки дані завантажуються
- **Empty state** — коли даних немає (наприклад, "У вас ще немає записів")
- **Error state** — коли запит не вдався
- **Success** — після успішної дії (запис підтверджено)

## 8. API-дані (що відображається)

### Запис (Appointment):
```
id, clientName, masterName, serviceName,
startAt (ISO datetime), endAt, status, price, source, notes
```

### Майстер:
```
id, name, specialization, photo (url|null)
```

### Послуга:
```
id, name, durationMinutes, price
```

### AI-рекомендація:
```
type, service.name, master.name,
suggestedDate, suggestedTimeSlots[],
confidence (0–1), reasoning (текст)
```

### AI-повідомлення в чаті:
```
role: "user" | "assistant",
content: string,
suggestions: string[],   // швидкі відповіді
actions: [{label, type}] // кнопки дій
```

## 11. Технічні обмеження для дизайнера

- Всі компоненти реалізуються через **shadcn/ui + Tailwind CSS** — бажано дизайнити в тій же стилістиці
- Анімації — мінімальні (fade, slide), без важких motion-ефектів
- Зображення майстрів — плейсхолдери (аватари з ініціалами), реальні фото опціонально
- Темна тема — **не потрібна** для MVP
- RTL — **не потрібна**
